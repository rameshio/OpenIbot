# Contributing to OpenIbot

Thank you for your interest in contributing!

## Code of Conduct

Please treat everyone with respect. Harassment or abusive behavior will not be tolerated.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Ensure all tests and type checks pass:
   ```bash
   npm install
   npm run typecheck
   npm test
   npm run build
   ```
5. Commit your changes (`git commit -m 'feat: add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Development Setup

See the `README.md` for full local development setup instructions.

Ensure you update `docs/code/README.md` and `docs/code/CHANGELOG.md` for any significant code changes according to our maintenance guidelines.
