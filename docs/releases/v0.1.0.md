# OpenIbot v0.1.0 — Initial Open-Source Release

Welcome to the initial open-source release of **OpenIbot**! 

OpenIbot is a multi-model AI agent workspace. Give it a task, choose your AI model, and watch specialized agents plan, collaborate, review, and produce the final result.

### What's included in v0.1.0:
- **Core Workspace:** A chat-based orchestrator that coordinates tasks among specialized bots.
- **Model Selection:** Bring your own API keys. Supports OpenAI, Anthropic, Google Gemini, xAI (Grok), and many others natively and via compatible endpoints (e.g., OpenRouter, local servers).
- **Agent Workflow:** Chief agent acts as orchestrator, planning steps and deploying specialized sub-agents with distinct roles and logic.
- **Available Views:** Chat view, Agents view, Graph view, and Files view for complete visibility over what the AI is doing.
- **Local Linux Workspaces:** Each bot has its own secure Docker-backed Linux workspace allowing isolated browsing, terminal access, and file operations.

### Installation

For this release, you must build the desktop application locally from source:

1. Clone the repository (`git clone https://github.com/rameshio/OpenIbot.git`)
2. Run `npm install`
3. Make sure Docker is running with the Linux engine
4. Run `npm run dev` to start developing, or `npm run package` to build the Windows `.exe`

### Current Limitations
- Windows is the only fully supported host operating system right now.
- APIs and workflows are experimental and may break or change in future updates.
- Workspaces require Docker Desktop to be active.
